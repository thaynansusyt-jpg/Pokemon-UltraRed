# Roadmap do Pokemon UltraRed

## Fase 0 - Aprendizado e validacao
- [ ] Entender `src/config.h`
- [ ] Rodar o primeiro teste no Actions
- [ ] Testar uma mudanca de `STANDARD_IV`
- [ ] Aprender a encontrar o primeiro erro no log

## Fase 1 - Compilacao real
- [ ] Identificar versoes das ferramentas devkitARM, Python, grit, wav2agb e mid2agb
- [ ] Construir workflow experimental que compile o motor
- [ ] Registrar o ambiente que funcionar
- [ ] Planejar um processo de patch que respeite direitos autorais

## Fase 2 - Primeira demo jogavel
- [ ] Construir uma versao de teste a partir de fonte autorizada
- [ ] Fazer uma mudanca pequena de gameplay
- [ ] Testar menus e uma batalha
- [ ] Registrar e corrigir bugs

## Fase 3 - Hack com identidade
- [ ] Definir proposta original
- [ ] Fazer um evento ou desafio marcante
- [ ] Produzir screenshots reais e creditos
- [ ] Compartilhar apenas patch com a comunidade

**Regra:** primeiro fazer uma pequena demonstracao funcionar; depois expandir.
